# Changelog

# 0.4.0

Changes

- Migrated settings to the new Obsidian settings API. This requires Obsidian version 1.13.0 or higher.
- Moved startup script management into a settings page with support for adding, removing, and reordering scripts.

Bug Fixes

- Fixed the left arrow key moving focus in the wrong direction in button prompts
- Fixed button prompt keyboard navigation in pop-out windows
- Improved safety of highlighted code rendering in execution statistics, with a plain-text fallback when highlighting fails

Misc

- Various internal improvements and dependency updates
- Fixed Obsidian review findings
